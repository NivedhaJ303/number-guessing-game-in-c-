# 🎯 Number Guessing Game in C++

A simple and fun console-based number guessing game written in C++. The computer randomly selects a number within a range, and the player has to guess it with hints provided along the way.

---

## 🚀 Features

- Random number generation
- User input and validation
- Feedback on each guess (too high / too low)
- Option to play again
- Clean and minimal code
